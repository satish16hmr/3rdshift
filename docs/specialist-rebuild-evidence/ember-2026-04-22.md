## 9-Section Structure Verified

Every output contains all 9 sections:
1. Brand Archetype (Jung's 12, primary + secondary)
2. Personality in 5 Words (each with Do/Don't and "Sounds like" example)
3. Voice Spectrums (6 axes as markdown table with percentages)
4. Voice Chart (Do/Don't per trait)
5. Vocabulary YES/NO (15-25 items each + preferred alternatives)
6. Before/After Examples (5-8 across content types)
7. Channel-Specific Adaptations (per selected channels)
8. AI Prompt Template (copy-paste ready for any AI tool)
9. Quick Reference Card (screenshot-ready summary)
